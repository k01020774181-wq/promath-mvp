# PROMATH 자체 서버 실행 안내

## 1. Windows에서 먼저 실행

Python 3.12 이상을 설치하고 프로젝트의 `server` 폴더에서 PowerShell을 엽니다.

```powershell
.\start.ps1
```

처음에는 가상 환경과 필요한 패키지를 설치하고 8080 포트로 서버를 실행합니다. 명령 실행이 정책상 제한되면 이 프로세스에만 아래 설정을 적용합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start.ps1
```

Python이 PATH에 없다면 실행 파일을 지정합니다.

```powershell
.\start.ps1 -Python 'C:\Python312\python.exe'
```

데이터는 `server/data`의 SQLite와 uploads 폴더에 저장됩니다. 서버 종료는 해당 창에서 Ctrl+C입니다. 실행 상태는 `http://localhost:8080/health`로 확인합니다.

## 2. 강사 계정 생성

새 PowerShell 창을 같은 server 폴더에서 열고 실행합니다.

```powershell
.\start.ps1 -Mode instructor -Username teacher -Name '강사 이름'
```

본인이 정한 10~128자 비밀번호를 두 번 입력합니다. 비밀번호 입력 내용은 화면에 표시되지 않습니다. 이 아이디와 비밀번호로 앱에서 로그인합니다. 같은 아이디가 이미 있으면 새 아이디를 사용합니다.

일반 회원가입은 학생만 생성합니다. 누구나 앱에서 강사 권한을 선택할 수 있게 만들지 않았습니다. 공유되는 기본 비밀번호나 테스트 계정을 넣지 않았습니다.

## 3. 휴대폰 연결

PC와 휴대폰을 같은 Wi-Fi에 연결합니다. PC의 `ipconfig`로 확인한 IPv4 주소가 예를 들어 `192.168.0.10`이라면 로그인 화면의 **연결 설정**에 `http://192.168.0.10:8080`을 입력합니다. PC 방화벽에서 해당 사설 네트워크의 TCP 8080 연결을 허용해야 합니다. PC가 켜져 있고 서버가 실행 중이어야 합니다.

Android Studio 기본 에뮬레이터는 `http://10.0.2.2:8080`을 사용합니다. 다른 장소의 학생이 접속하려면 아래 인터넷 서버를 배포해야 합니다. localhost를 다른 휴대폰의 서비스 주소로 입력하면 연결되지 않습니다.

## 4. 강의 등록

1. 강사 로그인 후 **강좌 만들기**를 누릅니다.
2. **차시 추가**에서 제목·단계·차시 번호를 입력합니다.
3. 차시를 열고 **강의 파일 업로드**로 MP4·WEBM·PDF 중 하나를 선택합니다. 최대 512MB입니다. 모바일 재생에는 일반적인 H.264/AAC MP4를 권장합니다. 이 서버는 영상을 변환하지 않습니다.
4. 업로드 완료 후 **차시 공개**를 켭니다.
5. 강좌 화면으로 돌아가 **강좌 공개**를 켭니다. 파일이 등록된 공개 차시가 1개 이상 필요합니다.
6. 학생은 회원가입하고 공개된 강좌와 차시를 볼 수 있습니다. PDF는 휴대폰에 설치된 PDF 뷰어로 열립니다.

학생이 새 강의를 확인하려면 홈의 새로고침을 누르거나 강좌를 다시 엽니다. 파일 교체는 기존 파일을 대체합니다. 현재는 차시당 한 개의 강의 파일을 관리합니다.

## 5. 인터넷 공개 — Linux 서버와 도메인 필요

준비물: 고정 공개 IP가 있는 Linux 서버, Docker Engine + Compose, 서버 IP를 가리키는 도메인의 DNS A 레코드. 서버의 TCP 80·443을 개방하고 `server` 폴더를 서버로 복사합니다.

```sh
cp .env.example .env
# .env의 PROMATH_DOMAIN을 실제 도메인으로 수정
docker compose up -d --build
docker compose exec api python app.py create-instructor --username teacher --name '강사 이름'
curl https://실제도메인/health
```

Caddy가 도메인 인증서를 발급하고 API로 연결합니다. API 컨테이너의 8080은 외부에 직접 노출하지 않습니다. 앱의 연결 설정에 `https://실제도메인`을 입력합니다. 모든 학생이 같은 주소에 연결해야 같은 강의를 봅니다. 이 설정 파일들은 준비했지만 이번 작업 환경에 Docker/공개 서버/도메인이 없어 실제 외부 배포는 수행하지 않았습니다.

Docker 데이터는 `platform_data` 볼륨, 인증서는 `caddy_data` 볼륨에 보존됩니다. 업데이트는 `docker compose up -d --build`로 합니다. 데이터 볼륨을 삭제하면 계정과 업로드가 사라지므로 보관해야 합니다. 백업에는 SQLite 데이터베이스와 uploads를 함께 포함하고, 복사 중 일관성을 위해 API를 중지하거나 SQLite 백업 기능을 사용하세요.

작은 규모의 단일 서버 기반입니다. 가입자 확대 전에는 저장 용량, 백업 복구, 로그·서비스 모니터링을 운영 환경에서 확인하세요. 현재 비밀번호 재설정과 이메일 인증은 구현하지 않았습니다.

## 6. 테스트

```powershell
.\start.ps1 -Mode test
```

테스트는 임시 데이터 폴더를 사용합니다. 실행 중인 서버의 계정이나 파일을 수정하지 않습니다.
